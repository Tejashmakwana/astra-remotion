# Astra Switch

A motion graphics film built with React and Remotion.

[Watch the video](https://x.com/aymannpk/status/2096649103619043400)

## Run

Requires Node.js 22 or newer.

```sh
npm ci
npm run studio
```

## Render

```sh
npm run render
```

Exports `out/astra-switch.mp4` at 1920 × 1080, 25 fps.

Edit `src/Film.tsx` to change the animation and copy. Required media lives in `public/`.

```sh
npm run typecheck
```
